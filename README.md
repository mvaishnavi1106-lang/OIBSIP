# LiveTalk Browser Chat Application

## Project Overview

LiveTalk is a real-time browser-based chat application developed using Flask and Socket.IO. It allows users to communicate through a public group chat as well as private messaging. The application provides an interactive chat experience with online user tracking, typing indicators, emoji support, chat history, and chat download functionality.

## Features

* Public Group Chat
* Private One-to-One Messaging
* Online Users List
* Typing Indicator
* Message Counter
* Emoji Support
* Download Chat as Text File
* Chat History Storage
* User Join and Leave Notifications
* Responsive User Interface

## Technologies Used

* Python
* Flask
* Flask-SocketIO
* HTML5
* CSS3
* JavaScript
* JSON (for storing chat history)

## How to Run

### 1. Install Required Packages

```bash
pip install flask flask-socketio
```

### 2. Run the Application

```bash
python app.py
```

### 3. Open in Browser

Visit:

```text
http://127.0.0.1:5000
```

### 4. Start Chatting

* Enter your username.
* Join the chat room.
* Send public messages.
* Select a user for private messaging.
* Use emojis and other chat features.
